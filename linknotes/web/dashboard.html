Kết nối kho note

    

      Dashboard đọc thẳng từ repo GitHub chứa note của bạn. Nó chỉ đọc,
      không bao giờ ghi — nên một token chỉ có quyền Contents: Read là đủ.
    


    

      
      
    

    

      
      
    

    
    

      Token lưu trong trình duyệt này (localStorage) và chỉ gửi tới api.github.com.
      Nếu bạn đã cấu hình app ghi link trên cùng tên miền thì các ô trên đã được điền sẵn.
    

    

      
    


    

    

      Không muốn dùng token? Nạp thẳng file JSON — các file YYYY-MM.json
      trong thư mục dữ liệu, hoặc file "Xuất JSON" từ app.
