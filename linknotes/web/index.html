Cài đặt & đồng bộ

Kho dữ liệu là một repo GitHub. Mỗi tháng một file JSON (YYYY-MM.json). Trên máy tính chỉ cần git pull là Claude Code đọc được toàn bộ note. Hãy dùng một repo private riêng — đừng để note cá nhân trong repo public.
Token chỉ nằm trong máy này (localStorage), không gửi đi đâu ngoài api.github.com. Tạo tại Settings → Developer settings → Personal access tokens → Fine-grained, chọn đúng repo trên, quyền Contents: Read and write.
Tự đồng bộ khi mở app và sau khi lưu
Tự lấy tiêu đề trang (cần Netlify function)
Hiện favicon (gọi google.com/s2/favicons — tắt nếu không muốn lộ tên miền)
